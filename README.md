# 평생 여행 로그 · Lifetime Travel Log

김상진님의 여행·수영대회 기록을 담는 인터랙티브 웹페이지입니다.

- 주소: <https://accseri-spec.github.io/travel-log/>
- 지도: 다녀온 나라 색칠 · 도시 핀 · 예정 항로 (Natural Earth 110m, 퍼블릭 도메인, Robinson 도법)
- ① 표지·통계 ② 준비·미확정·비상정보 ③ 11/19~28 날짜별 일정과 실제 기록·사진 ④ 수영대회 기록 ⑤ 예약 코드
- 상단 도구: **가+ 큰 글씨**, **한 장 요약**(가족 공유용), **백업(JSON) / 불러오기**

## 저장 방식

| 내용 | 저장 위치 |
| --- | --- |
| 일지·체크·대회 기록·설정·요약 | 이 브라우저의 `localStorage` (`travelLog.v1`) |
| 사진 (리사이즈 후 JPEG) | `IndexedDB` (`travelLogPhotos`), 실패 시 `localStorage` |
| 예약 코드 | 이 브라우저에만. 사이트에는 올리지 않음 |

기기를 바꾸거나 브라우저 데이터를 지우기 전에 **백업** 버튼으로 JSON 파일을 받아 두세요.
다른 기기에서는 **불러오기**로 그 파일을 열면 기록과 사진이 그대로 복원됩니다.

## 공개 페이지 주의

이 저장소는 공개이고 Pages 주소도 공개입니다. 여권번호·개인 휴대폰 번호·숙소 상세 주소(호실·출입정보)·예약번호(PNR)·등록번호는 넣지 않았습니다.
비상 연락처는 공개된 긴급·영사 번호만, 숙소는 도시·지역명까지만 적었습니다. 예약 코드는 ⑤번 화면에서 직접 입력하며 서버로 전송되지 않습니다.

## 파일

- `index.html` — 화면 뼈대
- `styles.css` — 모바일 우선 스타일 (큰 글씨 모드 포함)
- `data.js` — 초기 데이터 (일정·대회·체크리스트·비상정보)
- `app.js` — 지도·기록·사진·백업 로직
- `world.js` — 세계 국가 경계 좌표 (Natural Earth 110m, 퍼블릭 도메인)
