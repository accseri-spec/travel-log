# 상진의 운동 로그 (사이트)

가민 커넥트에서 받아 쌓은 수영·러닝·근력 기록을 한 화면에서 보는 정적 사이트입니다.
빌드 도구 없이 `index.html`을 열면 바로 동작합니다(외부 CDN·라이브러리 없음).

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 뼈대 (대회 D-day, 달력·합계·여닫이 요약, 월별 차트, 개인 최고·3K 페이스 비교, 11월 기록) |
| `styles.css` | 모바일 우선 스타일, "가+ 큰 글씨" 모드 |
| `data.js` | 가민에서 옮긴 초기 데이터(월별 누적·개인 최고·11월 기록 11건) |
| `app.js` | D-day 접기/펼치기, 달력(날짜 터치 이동), SVG 막대 차트, 종목 필터, 코치 코멘트, 메모·직접 입력 저장, 백업/복원 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리도록 하는 표식 |

## 기기에 저장되는 것

`localStorage` 키 `workoutlog.v1`에 컨디션 메모, 직접 추가한 운동, 큰 글씨 설정만 저장합니다.
`백업` 버튼으로 JSON 파일을 받아 두면 다른 기기에서 `불러오기`로 되살릴 수 있습니다.

## 공개 범위

이 사이트에는 이름 외에 이메일·가민 계정·전화번호·주소를 넣지 않았습니다.
직접 입력한 메모는 서버로 가지 않고 브라우저에만 남습니다.
